# StudySpace — Student Productivity Dashboard

A responsive student dashboard concept built with HTML5 and CSS3.

## Features
- Student-focused daily priorities
- Study timetable cards
- Overview cards and motivational reminder
- Responsive layout for mobile and desktop
- Semantic HTML and accessible labels

## Technologies
- HTML5
- CSS3
- Google Fonts (DM Sans and Manrope)

## Run locally
Open `index.html` in your browser.

## Deploy
This is a static website and can be published using GitHub Pages. See the official GitHub Docs:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Customization
Edit the sample tasks, study times, and labels in `index.html` to reflect your own design choices and workflow.
